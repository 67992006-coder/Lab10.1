# Sign Pose Trainer  
**เครื่องมือฝึกจำท่ามือเดี่ยว (Static Single-Hand Pose Trainer)**

เว็บแอปที่ให้คุณสอน AI ให้จำท่ามือเดี่ยว (เช่น ตัวสะกดนิ้วมือ) แล้วทำนายท่าได้แบบเรียลไทม์  
AI เรียนรู้จากตัวอย่างที่คุณสอนเอง และเก็บข้อมูลไว้ในเครื่องของคุณถาวร

> **ขอบเขตสำคัญ**  
> โปรเจกต์นี้รองรับเฉพาะ **ท่ามือเดี่ยวแบบนิ่ง (static single-hand pose)** เท่านั้น  
> ไม่ใช่ตัวแปลภาษามือแบบเต็มรูปแบบที่รองรับท่าเคลื่อนไหวหรือสองมือ

---

## คุณสมบัติหลัก

- เปิดกล้องเว็บแคม + แสดงจุดข้อต่อมือแบบเรียลไทม์
- โหมด **สอนท่า** – ใส่ชื่อท่าแล้วกดเพิ่มตัวอย่าง (แนะนำ 10–15 ตัวอย่างต่อท่า)
- โหมด **ทำนาย** – แสดงชื่อท่า + ความมั่นใจ (%) แบบเรียลไทม์  
  (ถ้าความมั่นใจต่ำกว่า 70% จะแสดง “ไม่แน่ใจ”)
- บันทึกท่าที่สอนไว้ใน **IndexedDB** (อยู่ถาวรข้ามเซสชัน)
- Export / Import ข้อมูลเป็นไฟล์ JSON
- ลบท่าทีละท่า หรือลบทั้งหมดได้
- ตัวเลือก “ลดความถี่ประมวลผล” สำหรับเครื่องที่ช้า
- **ประมวลผลทั้งหมดฝั่งผู้ใช้** – ไม่มีการส่งภาพหรือข้อมูลออกนอกเครื่องเลย

---

## เทคโนโลยีที่ใช้

| เทคโนโลยี       | หน้าที่                              |
|-----------------|--------------------------------------|
| HTML / CSS / JS | โครงสร้างและ UI (ไม่มี framework)   |
| ml5.js          | handpose (จับจุดมือ) + KNNClassifier |
| IndexedDB       | เก็บข้อมูลท่าที่สอนไว้ถาวร           |

## วิธีรันบนเครื่องตัวเอง

### วิธีที่ 1: เปิดไฟล์ตรง ๆ (ง่ายสุด แต่บางเบราว์เซอร์อาจจำกัดกล้อง)

1. ดาวน์โหลดหรือ clone โปรเจกต์นี้
2. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (Chrome / Edge / Firefox แนะนำ)

> หมายเหตุ: บางเบราว์เซอร์บังคับให้ใช้ HTTPS หรือ localhost ถึงจะอนุญาตกล้อง

### วิธีที่ 2: ใช้ Local Server (แนะนำ)

#### ใช้ Python (มีอยู่แล้วในเครื่องส่วนใหญ่)

```bash
# เข้าไปในโฟลเดอร์โปรเจกต์
cd sign-pose-trainer

# Python 3
python -m http.server 5500
```

แล้วเปิดเบราว์เซอร์ไปที่:  
[http://localhost:5500](http://localhost:5500)

#### ใช้ VS Code + Live Server

1. ติดตั้ง extension **Live Server**
2. คลิกขวาที่ `index.html` → Open with Live Server

#### ใช้ Node.js (serve)

```bash
npx serve .
```

## วิธี Deploy ขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub (เช่น `sign-pose-trainer`)
2. อัปโหลดไฟล์ทั้งหมดขึ้นไป (index.html, style.css, script.js, README.md)
3. ไปที่ **Settings → Pages**
4. ที่ Source เลือก branch `main` (หรือ `master`) และโฟลเดอร์ `/ (root)`
5. กด Save
6. รอสักครู่ แล้วจะได้ URL ประมาณ  
   `https://<username>.github.io/sign-pose-trainer/`

> **สำคัญ**: GitHub Pages ใช้ HTTPS อยู่แล้ว จึงสามารถขอสิทธิ์กล้องได้ปกติ

## วิธีใช้งานโดยย่อ

1. อนุญาตสิทธิ์กล้องเมื่อเบราว์เซอร์ถาม
2. สลับไปโหมด **สอนท่า**
3. พิมพ์ชื่อท่า (เช่น `ก`, `ข`, `สวัสดี`)
4. ทำท่ามือให้อยู่ในกล้อง แล้วกด **เพิ่มตัวอย่าง** ซ้ำ ๆ (แนะนำ 10–15 ครั้ง จากหลายมุม)
5. สลับกลับไปโหมด **ทำนาย** แล้วลองทำท่าดูผล

## ความเป็นส่วนตัว

- ภาพจากกล้องและจุดมือทั้งหมดถูกประมวลผล **เฉพาะในเบราว์เซอร์ของคุณ**
- ไม่มีการส่งข้อมูลไปเซิร์ฟเวอร์ใด ๆ
- ข้อมูลท่าที่สอนถูกเก็บใน IndexedDB ของเบราว์เซอร์เครื่องคุณเท่านั้น
